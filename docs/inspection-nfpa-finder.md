# NFPA inspection reference finder

Research completed September 25, 2026 (America/Chicago).

- Reviewed all nine public pages of NFPA's codes and standards directory: 424 unique document numbers; 48 entries on pages 1–8 and 40 on page 9.
- Stored directory numbers, titles, and exact official links, with the observed directory page. These include specialized, historic, and potentially developing documents. The snapshot is not an adopted-code list or a promise that every entry has free access.
- Reviewed public edition selectors and the actual “View Free Access” targets for 32 inspection-related references, including 41 edition-specific links. Some publisher-listed editions have a 2027 year. That year was observed, not inferred from today's date. Nine common references also have their previous-edition link verified.
- NFPA 10 (2026) free view was opened after the user authorized accepting its access terms. Reviewed its chapter navigation and 7.2 inspection content. The finder provides an original observation prompt and a chapter-reading hint; it does not reproduce the standard's requirements or prescribe inspection intervals.
- The other 31 references have verified public metadata and free-view link destinations. Their complete book contents were not reviewed in this task. Original prompts describe information to collect and research, without numerical requirements, invented section citations, or automatic compliance judgments.

## Use

Fire Inspections → NFPA finder, or an inspection's Plan → Find an NFPA reference / add research checkpoints. Code library includes a shortcut. Search works across all directory entries; browse defaults to the 32 inspection references. Topic filters and paginated results keep the initial view small.

Selected research editions and official/free-view URLs are copied into saved checkpoints. They remain Not checked, with empty observations and citations. Adding checks clears earlier signatures and review acknowledgment, rejects overflow, and prevents duplicate identical sources. Existing property code basis is untouched. Saved checks expose clickable source links. Use Code library for department-approved reusable citations and wording.

The finder is lazy loaded and static: no extra database tables, background polling, scraping service, account credentials, or NFPA book content. It remains inside the existing owner-only private inspection module.

## Updating

Review the official directory and publication pages again before updating the checked date or link snapshot. Do not generate edition links by substituting years. Only add an exact link after observing the publisher's free-view target for that edition. Preserve older saved checkpoint sources and department-edited code entries.
